# Customer Churn Prediction

## Project Overview

This project focuses on analysing customer churn and predicting customers who may be at risk of leaving a business.

The project uses Python, exploratory data analysis, machine learning, model evaluation, and SHAP explainability to generate actionable customer retention insights.

## Objectives

- Understand customer churn patterns.
- Perform exploratory data analysis.
- Train and compare machine learning models.
- Evaluate model performance.
- Analyse classification thresholds.
- Interpret predictions using SHAP.
- Develop business recommendations.

## Tools and Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- SHAP
- Jupyter Notebook
